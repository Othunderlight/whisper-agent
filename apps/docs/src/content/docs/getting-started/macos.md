## Download

Download the latest release from [ryoiki-tenkai.com/download](https://ryoiki-tenkai.com/download).

1. Open the downloaded `.dmg` file.
2. Drag the Ryōiki Tenkai icon into the Applications folder.
3. Eject the disk image.
4. Open Ryōiki Tenkai from your Applications folder. On first launch, macOS may ask you to confirm since the app was downloaded from the internet — click **Open**.

## Homebrew

You can also install Ryōiki Tenkai via [Homebrew](https://brew.sh):

```bash
brew tap ryoiki-tenkai/ryoiki-tenkai
brew install --cask ryoiki-tenkai-desktop
```

Upgrade with:

```bash
brew upgrade --cask ryoiki-tenkai-desktop
```

To install the development channel instead:

```bash
brew install --cask ryoiki-tenkai-desktop-dev
```
