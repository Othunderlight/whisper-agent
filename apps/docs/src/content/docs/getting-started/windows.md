## Download

Download the latest release from [ryoiki-tenkai.com/download](https://ryoiki-tenkai.com/download).

1. Run the downloaded `.exe` installer.
2. Follow the on-screen prompts to complete the installation.
3. Ryōiki Tenkai will be available from the Start menu.
